A neural network learns the way your brain does

The first time you tasted Hyderabadi biryani, your brain noted the smell, spice and colour. Nobody gave you a rule book. A neural network learns the same way: from many examples.

★★ Board definition
A neural network is a machine learning model that makes decisions in a manner similar to the human brain, by using processes that mimic the way biological neurons work together to identify phenomena, weigh options and arrive at conclusions.

Main advantage: it extracts features from data automatically, without the programmer telling it what to look for.

Seen daily in: Gmail spam filter, suggested replies, photo tagging, shopping suggestions, Google Search.

Bias and threshold: two ways questions are asked

Read the question first. Is a bias given, a threshold, or both?

Style A: bias and threshold both given

z = w₁x₁ + w₂x₂ + w₃x₃ + b

Compare z with the threshold T.
z ≥ T → output 1 (fires)
z < T → output 0

Handbook Case I: bias 0.1, threshold 3.0.

Style B: threshold turned into bias

b = −T,  z = Σwx − T

Now compare z with 0.
z ≥ 0 → output 1 (fires)
z < 0 → output 0

Handbook surfing example: threshold 3 means bias −3.

The trap students fall into

Suppose Σwx = 5 and threshold T = 3. In Style B, z = 5 − 3 = 2.

Correct: 2 ≥ 0, so output = 1. (Same as checking 5 ≥ 3.)

Wrong: 2 < 3, so output = 0. This subtracts the threshold twice.

Rule: subtract the threshold once, or compare with it once. Never both. If z equals the threshold exactly, the neuron fires (≥).

    How a network learns: predict, measure, correct

    Like throwing a paper ball into the dustbin: miss, adjust your aim, throw again. A caterer bills 4 plates at ₹1000. The network must learn the price per plate (the weight).

    Forward pass: predict ŷ = w × 4→Error = 1000 − ŷ→Backpropagation: adjust w↺

    Weight now: ₹100 per plate

    Prediction ŷ: ₹400

    Error: ₹600

    ★★ Backpropagation fine-tunes the weights using the error (loss) of the previous epoch. One epoch = one full pass through the training data.

    GAN: a forger and a checker improve together

    The generator forges a signature. The discriminator compares it with the real one. Every time the fake is caught, the generator gets better.

    ★★ GAN = Generator (creates fake samples) + Discriminator (judges real vs fake), trained against each other. Used for image generation, style transfer and data augmentation.

    Like turning a long trip into a short voice note (encoder) that a friend can picture again (decoder). The short version is the latent space.

    LLM: predicting the next word, again and again

    Your phone keyboard guesses the next word. A Large Language Model does this after reading trillions of words. Tap a word to continue the sentence.

    ★★ A Large Language Model is a deep learning algorithm that performs NLP tasks such as generating and classifying text, answering questions conversationally and translating languages. It is “large” because it is trained on massive datasets of text and code.

    Limitations: needs huge computing power; can state wrong facts confidently; may memorise instead of generalise.
